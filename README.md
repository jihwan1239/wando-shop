# 🐟 청해진 건어물

완도 바닷바람에 건어물을 말려 파는 픽셀 힐링 가게 키우기 게임이에요.

서울살이에 지친 주인공이 허리를 다친 할머니 대신 완도항의 작은 건어물 가게를 맡게 되면서 이야기가 시작돼요. 멸치 한 바구니와 건조대 두 칸으로 시작해서, 해녀 이모와 선장님, 알바생 동수의 도움을 받아 가게를 키워갑니다.

이 게임은 성남에 있는 실제 건어물 가게 **완도어람건어물**을 모티브로 만들었어요. 게임 안 「우리 가게」 탭에서 진짜 가게를 구경할 수 있어요.

**완도어람건어물**
- 주소: 경기 성남시 수정구 수정북로 28 1층
- 전화: 010-9437-4367
- 가게 정보: https://naver.me/GSgVA9Op

## 플레이 방법

- 건조대 빈칸을 눌러 건어물을 걸어요. 다 마르면 눌러서 거둬요.
- 손님이 말풍선으로 원하는 상품을 보여주면, 손님을 눌러 팔아요. 직접 응대하면 10% 더 받아요.
- 갈매기 깍깍이와 고양이 치즈가 건어물을 노려요. 눌러서 쫓아주세요.
- 번 돈으로 새 상품을 들여오고 가게를 키워요.

## 게임 내용

**상품**
멸치, 미역, 다시마, 김, 오징어, 건전복까지 완도 특산물 6가지를 차례로 들여올 수 있어요.

**가게 키우기**
건조대 늘리기, 선풍기, 예쁜 포장, 간판 꾸미기, 알바생 고용, 자동 건조 시스템

**이야기**
상품을 들여오거나 가게가 유명해질 때마다 새 이야기가 열려요. 본 이야기는 「우리 가게」 탭에서 다시 볼 수 있어요.

**배경음악**
마림바 멜로디와 파도 소리가 흐르는 바닷가 BGM이 있어요. 오른쪽 위 ♪ 버튼에서 배경음악과 효과음을 따로 끌 수 있어요.

**방치형**
알바생을 고용하면 앱을 꺼둬도 가게가 돌아가요. 다시 들어오면 그동안 번 돈을 정산해줘요. (최대 3시간)

## 파일 구성

```
index.html            게임 본체 (화면, 게임 코드, 픽셀 그림 전부 포함)
manifest.json         웹앱 설정 (이름, 아이콘, 테마 색)
sw.js                 오프라인 실행용 서비스워커
icon-192.png          앱 아이콘
icon-512.png          앱 아이콘
apple-touch-icon.png  아이폰 홈 화면 아이콘
```

## 홈 화면에 추가하기

- **아이폰**: 사파리로 접속 → 공유 버튼 → 홈 화면에 추가
- **안드로이드**: 크롬으로 접속 → 메뉴 → 앱 설치 또는 홈 화면에 추가

한 번 접속하고 나면 인터넷이 없어도 플레이할 수 있어요. 진행 상황은 각자 기기 브라우저에 저장돼요.

## 가게 정보 바꾸기

`index.html` 맨 위의 `CONFIG`만 고치면 게임 전체에 반영돼요.

```js
const CONFIG = {
  shopName: '청해진 건어물',        // 게임 속 가게 이름 (간판)
  realShopName: '완도어람건어물',   // 실제 가게 이름
  shopIntro: '...',                 // 가게 소개 문구
  shopUrl: '',                      // 실제 가게 링크
  shopAddress: '',                  // 주소
  shopPhone: '',                    // 전화번호
  supportAccount: '',               // 응원 계좌 (비워두면 버튼 숨김)
};
```

## 업데이트할 때

파일을 고쳐서 다시 올릴 때는 `sw.js` 첫 줄의 버전을 하나씩 올려주세요.

```js
const VERSION = 'wando-shop-v4';   // → v5, v6 ...
```

그래야 이미 설치한 사람들도 새 아이콘과 파일을 받아요.
