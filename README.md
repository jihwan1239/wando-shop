# 🐟 청해진 건어물

완도 바닷바람에 건어물을 말려 파는 픽셀 힐링 가게 키우기 게임이에요.

서울살이에 지친 주인공이 허리를 다친 할머니 대신 완도항의 작은 건어물 가게를 맡게 되면서 이야기가 시작돼요. 멸치 한 바구니와 건조대 두 칸으로 시작해서, 해녀 이모와 선장님, 알바생 동수의 도움을 받아 가게를 키워갑니다.

이 게임은 성남에 있는 실제 건어물 가게 **완도어람건어물**을 모티브로 만들었어요. 게임 아래 메뉴의 「진짜 가게」에서 진짜 가게를 구경할 수 있어요.

**완도어람건어물**
- 주소: 경기 성남시 수정구 수정북로 28 1층
- 전화: 010-9437-4367
- 가게 정보: https://naver.me/GSgVA9Op

## 화면 구성

- 위쪽: 가진 돈, 가게 레벨과 경험치, 오늘의 할 일, 소리 설정, 도움말
- 가운데: 가게 화면. 남는 공간은 하늘과 항구 바다로 채워져요.
- 아래쪽 메뉴: 창고, 주문, 키우기, 수첩, 진짜 가게. 할 일이 있으면 빨간 점이 떠요.

## 플레이 방법

- 건조대 빈칸을 눌러 건어물을 걸어요. 다 마르면 눌러서 거둬요.
- 손님이 말풍선으로 원하는 상품을 보여주면, 손님을 눌러 팔아요. 직접 응대하면 10% 더 받아요.
- 갈매기 깍깍이와 고양이 치즈가 건어물을 노려요. 눌러서 쫓아주세요.
- 번 돈으로 새 상품을 들여오고 가게를 키워요.
- 가게 앞에서 낮잠 자는 치즈를 쓰다듬으면 작은 보너스가 있어요.

## 게임 내용

**레벨**
번 돈, 오늘의 할 일, 멸치 받기로 경험치가 쌓여 가게 레벨이 올라요. 레벨이 오를 때마다 보너스 돈을 받고, 레벨업 창에서 새로 열린 것과 다음 목표를 보여줘요. 위쪽 Lv 버튼 → 「레벨 보상」에서 Lv 30까지 무엇이 열리는지 미리 볼 수 있어요. 가게 칭호는 11단계이고, Lv 4, 8, 13, 20에는 새 이야기가 열려요. 하루에 몇 번 잠깐씩 들어오면 엔딩(Lv 20)까지 1주일 남짓 걸리고, 그 뒤로도 Lv 30까지 키울 수 있어요.

새 상품은 정해진 레벨이 돼야 들여올 수 있어요 (미역 Lv 2, 다시마 Lv 4, 김 Lv 7, 오징어 Lv 11, 건전복 Lv 15).

**오늘의 가게 (위쪽 Lv 버튼)**
- 오늘의 할 일: 매일 3개(Lv 9부터 4개)가 나와요. 하나 끝낼 때마다 돈과 경험치를 받고, 다 끝내면 보상 상자(돈, 경험치, 햇살 버프)를 열 수 있어요.
- 출석: 하루에 한 번 들어오면 7일 주기로 보상을 받고, 7일째엔 선물이 있어요.
- 놀이 멸치 받기 (Lv 3): 30초 동안 박 선장님 배에서 쏟아지는 멸치와 미역을 소쿠리로 받아요. 황금 멸치는 5점, 해파리와 장화는 감점이에요. 하루 3판(Lv 6부터 4판).

**항구 풍경**
레벨이 오르면 항구가 점점 붐벼요. 박 선장님 고깃배(Lv 3), 섬 위 빨간 등대(Lv 5), 김 양식장 부표(Lv 7), 청산도 여객선(Lv 9), 갈매기 떼(Lv 12), 방패연(Lv 14), 고래(Lv 18), 밤 불꽃놀이(Lv 20), 열기구(Lv 25), 황금 돛단배(Lv 30)가 차례로 생겨요.

**상품**
멸치, 미역, 다시마, 김, 오징어, 건전복까지 완도 특산물 6가지를 차례로 들여올 수 있어요.

**단골 주문**
할머니, 해녀 이모, 박 선장님, 동수, 서울 택배 손님이 건어물을 한꺼번에 주문해요. 모아서 보내면 큰 보상을 받아요.

**건어물 도감**
상품을 많이 팔면 동, 은, 금 도장을 받고, 도장마다 그 상품 판매가가 5% 올라요.

**장날**
가끔 완도 장날이 열려서 60초 동안 손님이 몰려오고 판매가가 20% 올라요.

**가게 키우기와 꾸미기**
건조대 늘리기, 선풍기, 예쁜 포장, 간판 꾸미기, 알바생 고용, 자동 건조 시스템에 더해 화분, 치즈 방석, 풍경, 줄전구, 풍어기, 간판 새단장으로 가게를 꾸밀 수 있어요. 꾸미기 소품마다 작은 효과가 있고, 레벨이 오르면 하나씩 열려요.

업그레이드를 하면 가게 외관도 함께 바뀌어요. 간판 꾸미기 단계마다 청사초롱, 멸치 장식, 반짝이 전구, 입간판, 풍선, 지붕 위 멸치 바람개비가 생기고, 선풍기와 선물상자, 알바생 동수, 자동 건조 톱니바퀴도 화면에 나타나요. 가게 레벨 8에는 기와 지붕, 13에는 금색 술 장식, 20에는 간판 위 금별이 생겨요.

**바닷가 친구들**
가끔 돌고래가 뛰어오르고, 꽃게가 길을 지나가고, 갈매기가 건조대 기둥에 쉬러 와요. 꽃게를 눌러 바다로 돌려보내면 작은 보너스가 있어요.

**숨은 재미**
게임 곳곳에 이스터에그 9개가 숨어 있어요. 「수첩」 → 「숨은 재미」에서 찾은 개수와 힌트를 볼 수 있어요.

**이야기**
상품을 들여오거나 가게가 유명해질 때마다 새 이야기가 열려요. 본 이야기는 「수첩」 → 「이야기」에서 다시 볼 수 있어요.

**배경음악**
마림바 멜로디와 파도 소리가 흐르는 바닷가 BGM이 있어요. 오른쪽 위 스피커 버튼에서 배경음악과 효과음을 따로 끌 수 있어요.

**방치형**
알바생을 고용하면 앱을 꺼둬도 가게가 돌아가요. 다시 들어오면 그동안 번 돈을 정산해줘요. 혼자 가게를 보는 동수는 손님을 다 받지 못해서, 직접 플레이할 때보다는 천천히 벌어요. (최대 3시간)

## 파일 구성

```
index.html            게임 본체 (화면, 게임 코드, 픽셀 그림 전부 포함)
manifest.json         웹앱 설정 (이름, 아이콘, 테마 색)
sw.js                 오프라인 실행용 서비스워커
icon-192.png          앱 아이콘
icon-512.png          앱 아이콘
apple-touch-icon.png  아이폰 홈 화면 아이콘
```

## 홈 화면에 추가하기

- **아이폰**: 사파리로 접속 → 공유 버튼 → 홈 화면에 추가
- **안드로이드**: 크롬으로 접속 → 메뉴 → 앱 설치 또는 홈 화면에 추가

한 번 접속하고 나면 인터넷이 없어도 플레이할 수 있어요. 진행 상황은 각자 기기 브라우저에 저장돼요.

## 가게 정보 바꾸기

`index.html` 맨 위의 `CONFIG`만 고치면 게임 전체에 반영돼요.

```js
const CONFIG = {
  shopName: '청해진 건어물',        // 게임 속 가게 이름 (간판)
  realShopName: '완도어람건어물',   // 실제 가게 이름
  shopIntro: '...',                 // 가게 소개 문구
  shopUrl: '',                      // 실제 가게 링크
  shopAddress: '',                  // 주소
  shopPhone: '',                    // 전화번호
  supportAccount: '',               // 응원 계좌 (비워두면 버튼 숨김)
};
```

## 업데이트할 때

파일을 고쳐서 다시 올릴 때는 `sw.js` 첫 줄의 버전을 하나씩 올려주세요.

```js
const VERSION = 'wando-shop-v12';   // → v13, v14 ...
```

그래야 이미 설치한 사람들도 새 아이콘과 파일을 받아요.
